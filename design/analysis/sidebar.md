## Как проверить после правок

```bash
CLI="$HOME/Library/Application Support/ArtCraft/mcp/cli/figcraft-cli"
"$CLI" export design/salt-md.figcraft --node 163 --scale 2 -o tmp/agent-sidebar/fig-document-2x.png
"$CLI" export design/salt-md.figcraft --node 234 --scale 2 -o tmp/agent-sidebar/fig-collection-2x.png
python3 tmp/agent-sidebar/anchors.py     # эталон/макет: bbox ключевых элементов
python3 tmp/agent-sidebar/dump_tree.py   # геометрия слоёв 163/234 в tree.json
```

`anchors.py`/`dump_tree.py`/`measure.py` лежат в `tmp/agent-sidebar/` (в git не добавлялись); цифры в
таблице сняты ими на снимке `a42e101`.

## Оговорки

- Значения `y` для текстовых слоёв в FigCraft и caps-боксы в браузере расходятся на 2–3 px из-за
  разных line-box; в таблице для FigCraft указаны bbox рендера, для эталона — bbox пикселей.
- Активная строка в `sidebar-tree.png` (163) — «Welcome to salt.md» с эмодзи: там карточка 41 px
  (строка 42 px), в `collection-table.png` (234) — «Tasks»: карточка 36 px. Поэтому строка 4 даёт
  разные цели для 163 и 234.
- Файл макета правился параллельно; если какая-то строка уже закрыта — сверяться с колонкой
  «эталон», она неизменна.
