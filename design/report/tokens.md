## Reading this

- **match**: the design token and its CSS counterpart carry the same value in every mode the design has.
- **diff**: both sides exist and disagree. Either the design or the code is stale; decide which.
- **missing**: the design token has no CSS counterpart at all. Colour tokens that are missing are gaps in `theme.css`; spacing, size and type tokens are literals in `styles.css` today, so those rows are the case for a scale rather than a bug.
